## Overview

**Architecture Bulletin** is a modern web application for managing team deliverables and task assignments. It uses GitHub as the backend storage, allowing teams to:

- 📝 Post bulletin messages with attachments
- 👥 Assign tasks to team members
- 📊 Track task status (New, Assigned-InProgress, Closed)
- 💬 Engage in threaded conversations
- 📎 Upload and manage deliverable artifacts
- 🔐 Authenticate via GitHub OAuth

## Features

### For Admins
- Create and manage bulletin posts
- Attach artifacts to bulletins
- Assign tasks to architects
- Monitor task progress
- Engage in closure conversations

### For Architects
- View bulletin board
- Self-assign or be assigned tasks
- Update task artifacts
- Participate in threaded discussions
- Track personal task assignments

## Tech Stack

- **Frontend**: Vite + React (JavaScript)
- **Styling**: Tailwind CSS
- **State Management**: Context API + Hooks
- **Routing**: React Router
- **Backend**: GitHub API (Octokit)
- **Authentication**: GitHub OAuth
- **Deployment**: GitHub Pages
- **Testing**: Vitest + React Testing Library

## Quick Start

### Prerequisites

- Node.js >= 18.0.0
- npm >= 9.0.0
- GitHub account

### Installation

1. Clone the repository
2. Navigate to the project directory:
   ```bash
   cd Architecture-Bulletin
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Set up environment variables:
   ```bash
   cp .env.example .env
   # Edit .env with your GitHub OAuth credentials
   ```
5. Start the development server:
   ```bash
   npm run dev
   ```

For detailed setup instructions, see [WORKSPACE_SETUP.md](./WORKSPACE_SETUP.md).
